# What is Cloud Computing?
----
## The Evolution of Cloud Computing
### ON-Premises
Benefits:
* You control and own all the data and infrastructure.
* Easier regulations over compliance.
* Specialized deployments.

Drawbacks:
* High costs.
* Not as efficent in utilzation - not agile.
* Requires long-term accurate planning.

### Hosted Data Centers
Benefits:
* The provided maintains the resources and storage for you.
* No data center building requirement.
* Physical Security Offloading.

Drawbacks:
* Costs
* Maintenance and Planning

### Cloud Computing
Benefits:
* No cpaital hardware costs.
* Agile
* Redundant
* Global

Drawbacks:
* Learning curve - Its a different system, its a different world.
* Possible complexities. - Integrating things on the cloud to on-premeises can be complex.
